# LabSummit — симулятор международного саммита

Учебная консольная программа на Java, моделирующая обсуждение вопросов и голосование представителей стран.

## Возможности

- формирование списка из 30 стран, распределённых по заданным группам;
- случайный выбор семи вопросов для заседания;
- ввод голоса России пользователем;
- моделирование голосов стран по упрощённым правилам политических блоков и случайному выбору;
- подсчёт голосов за, против и воздержавшихся;
- итоговый отчёт о принятых и отклонённых решениях.


## Технологии

- Java 14 или новее;
- стандартная библиотека Java (`Random`, `Scanner`).

## Запуск

Открой проект в IntelliJ IDEA и запусти класс `LabSummit.Solo`. Исходный файл должен находиться в каталоге `src/LabSummit/Solo.java`.
